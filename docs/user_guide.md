# دليل التشغيل والاستخدام للنظام (User Guide)

هذا الدليل يشرح خطوة بخطوة كيفية استخدام وتشغيل أنبوب البيانات (Big Data Pipeline) الخاص بمشروع التجارة الإلكترونية.

---

## 1. المتطلبات الأساسية (Prerequisites)
قبل تشغيل النظام، تأكد من توفر التالي على جهازك:
- **لغة Python** (الإصدار 3.9 فأحدث).
- **قاعدة بيانات MongoDB** تعمل محلياً على المنفذ الافتراضي (`mongodb://localhost:27017`).
- **Apache Spark** (مثبت ومعرف في متغيرات البيئة).
- المكتبات البرمجية المطلوبة (يمكن تثبيتها عبر: `pip install pymongo pyspark`).

---

## 2. هيكلية ملفات البيانات
يجب وضع ملفات البيانات (CSV) التي تريد معالجتها داخل مجلد `data`.
- الملفات الكبيرة توضع في: `data/raw/`
- العينات الصغيرة توضع في: `data/samples/`

---

## 3. كيفية تشغيل النظام

النظام مصمم بذكاء لاختيار محرك المعالجة المناسب بناءً على حجم الملف تلقائياً. كل ما عليك فعله هو تشغيل الملف الرئيسي `src/main.py` وتمرير مسار الملف المراد معالجته.

### أ. تشغيل النظام على عينة صغيرة (أقل من 200 ميجابايت)
سيقوم النظام تلقائياً باستخدام محرك **Python Batch Loader**:
```powershell
python src/main.py --file-path data/samples/orders_sample_10k.csv
```

### ب. تشغيل النظام على ملف ضخم (أكبر من 200 ميجابايت)
سيقوم النظام تلقائياً باكتشاف الحجم واستخدام محرك **PySpark Distributed Loader** لضمان سرعة المعالجة وعدم استهلاك الذاكرة:
```powershell
python src/main.py --file-path data/raw/orders_huge_mixed_quality.csv
```

---

## 4. تنظيف قاعدة البيانات (إعادة الضبط)
إذا أردت إجراء تجربة جديدة تماماً وحذف جميع السجلات القديمة لتوفير المساحة أو بدء تشغيل نظيف، استخدم الأمر التالي:
```powershell
python -c "from pymongo import MongoClient; MongoClient('mongodb://localhost:27017').drop_database('midterm_data_pipeline')"
```

---

## 5. مخرجات النظام والتقارير

بمجرد اكتمال التشغيل (والذي قد يستغرق من ثوانٍ للعينات إلى ساعات للملفات الضخمة)، سيقوم النظام بالتالي:
1. **الطباعة على الشاشة:** عرض ملخص نهائي يوضح عدد السجلات السليمة، المصححة، والمعزولة، بالإضافة إلى نتيجة معادلة الاتساق `Consistency Check: PASSED ✅`.
2. **توليد التقارير:** سيتم إنشاء/تحديث ملفين في مجلد `reports/`:
   - `results.json`: تقرير تقني مفصل يحتوي على كل المقاييس (وقت التنفيذ، معدل النقل Throughput، تفاصيل الـ Upsert).
   - `results.md`: تقرير منسق وسهل القراءة.
3. **قاعدة البيانات:** يمكنك فتح `MongoDB Compass` والاتصال بـ `localhost:27017` لاستعراض الجداول الثلاثة (`orders_raw`, `orders_validated`, `orders_quarantine`).

---

## 6. ملاحظات هامة حول إعدادات المعالجة الضخمة (PySpark)
تمت تهيئة النظام ليعمل بشكل مستقل ويتفادى أخطاء الذاكرة (Out Of Memory) للملفات الضخمة:
- تم تخصيص **8 جيجابايت** من الذاكرة لـ PySpark بشكل افتراضي (`spark.driver.memory`).
- تم تعديل خيارات قراءة الـ CSV (`escape char`) لضمان قراءة ملفات الـ JSON المدمجة داخل الـ CSV بشكل مثالي دون تكسير الأعمدة.
